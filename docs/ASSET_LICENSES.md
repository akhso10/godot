# Sumber aset dan pemberitahuan hak cipta

| Kelompok | Asal | Keterangan distribusi |
| --- | --- | --- |
| Ilustrasi, potret, dan gambar sinematik | Ilustrasi dibuat untuk *Sekolah Setelah Tengah Malam* menggunakan ImageGen. Tangkapan lingkungan 3D berasal dari proyek Godot. | Disertakan dalam proyek dan paket aset ini. |
| Model, rig, animasi, ikon inventaris | Model dibuat melalui skrip Blender di `tools/`. Ikon dan studi karakter dirender dari model proyek. | Model dan render asli proyek. |
| Tekstur material dan efek visual | Generator permukaan dan efek dalam `tools/`. | Aset asli proyek. |
| Musik, suasana, langkah kaki, efek interaksi | Sintesis untuk proyek melalui `tools/synthesize_audio.py`. | Aset audio asli proyek. |
| Lambang sekolah, ikon dan antarmuka | Gambar vektor dan raster dibuat untuk proyek. | Aset asli proyek. |
| Open Sans | Google Corporation, distribusi Debian fonts-open-sans. | Apache License 2.0. Teks lisensi dan pemberitahuan disertakan di `assets/ui/fonts/`. |
| DejaVu Serif Condensed | Distribusi DejaVu Fonts, berbasis Bitstream Vera. | Bitstream Vera Font License. Perubahan oleh DejaVu berada dalam domain publik. Pemberitahuan lengkap di `assets/ui/fonts/LICENSE-DejaVu.txt`. |
| Godot dan komponen dalam ekspor Windows | Distribusi resmi Godot 4.7.2. | Lisensi Godot MIT dan lisensi komponen pihak ketiga tercantum di `docs/licenses/GODOT-NOTICES.txt`, diambil dari binary Godot yang dipakai untuk ekspor. |

Publikasi GitHub memberi akses untuk melihat dan mengunduh proyek. Pemilik belum menentukan lisensi penggunaan ulang umum untuk kode, cerita, dan aset asli. Ketentuan font dan komponen mesin berlaku sesuai pemberitahuan masing-masing.

Manifest di akar repositori mencantumkan jalur, ukuran byte, dimensi gambar, sumber dan SHA-256 setiap aset. Kolom `generation_prompt` mengacu ke bagian spesifikasi artistik asli dalam master prompt. Kolom itu mendokumentasikan brief, bukan transkrip panggilan generator. Berkas lisensi, metadata `.import` dan cache editor berada di luar perhitungan jumlah aset.
